Sleep Timer

Sleep button: not installed on this device

The sleep timer adds a button to the video player OSD next to the subtitle button. Click it to set a duration that stops playback automatically. When the timer reaches zero, an "Are you still watching?" dialog appears -- playback only stops if the dialog is dismissed or ignored.

Server Settings

How long the "Are you still watching?" dialog stays before playback stops automatically. Set to 0 to stop immediately.
When unchecked, playback stops immediately when the timer expires with no dialog.
Used as the starting value when setting a timer. The player always sends an explicit duration.
